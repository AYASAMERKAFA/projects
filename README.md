# Mini Commerce Management System

A CLI Python review project covering fundamentals, files/exceptions/modules, OOP/type hints/domain modeling, testing, generators, decorators, logging, aggregation and basic performance thinking.

## Run
`python main.py`

## Tests
`pytest -q`

## Structure
- `store/models`: domain models
- `store/services`: business logic
- `store/storage`: JSON persistence and CSV export
- `tests`: business-rule tests
- `data`: products, customers and orders JSON
- `logs`: application log
